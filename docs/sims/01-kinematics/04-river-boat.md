# Harakatning nisbiyligi

<SimLab id="river-boat" />

## Asosiy ğoya

Tezlik nimaga nisbatan ölçanayotgani, yaʼni qaysi sanoq sistemasi tanlangani aytilgandagina maʼnoga ega böladi. Qayiqning suvga nisbatan tezligi uning qirğoqqa nisbatan tezligiga teng emas, çunki suvning özi ham harakatlanadi. Harakatlanayotgan havoda uçayotgan samolyot yoki ketayotgan poyezd vagoni içida yurib borayotgan odam uçun ham xuddi şunday. Bu *harakatning nisbiyligi* deyiladi.

Ikki sanoq sistemasidagi tezliklarni boğlovçi qoida sodda — bu *tezliklarni qöşiş qonuni*: tezliklar vektor sifatida qöşiladi. Qayiqning qirğoqqa (qözğalmas sanoq sistemasiga) nisbatan tezligi uning suvga (harakatlanuvçi sanoq sistemasiga) nisbatan tezligi bilan suvning qirğoqqa nisbatan tezligi yiğindisiga teng. Şuning uçun daryoni kesib ötayotgan qayiq jönagan joyining röparasiga yetib borişi uçun uni oqimga qarşi burib boşqariş kerak. Yon şamolda qönayotgan samolyot esa uçiş-qöniş yölagi böylab töğri harakatlanayotganda burnini şamolga qaratib turadi.

## Nazariya

Tezliklar vektor sifatida qöşiladi. Qayiq suvga nisbatan özi yönaltirilgan tomonga ${\vec\upsilon}'$ tezlik bilan harakatlanadi, suvning özi esa daryo böylab $\vec u$ tezlik bilan oqadi. Qirğoqqa, yaʼni qözğalmas sanoq sistemasiga nisbatan qayiqning tezligi bu ikki tezlikning yiğindisiga teng (*tezliklarni qöşiş qonuni*):

<div class="eq-block">

<span class="eq-body">$\displaystyle \vec\upsilon = {\vec\upsilon}' + \vec u$</span>

<span class="eq-label">Kesib ötiş vaqti</span><span class="eq-body">$\displaystyle t = \frac{d}{\upsilon'\cos\alpha}$</span>

<span class="eq-label">Oqim böylab suriliş</span><span class="eq-body">$\displaystyle x = (u - \upsilon'\sin\alpha)\,t$</span>

<span class="eq-label">Röparadagi nuqtaga yetiş şarti</span><span class="eq-body">$\displaystyle \sin\alpha = \frac{u}{\upsilon'}$</span>

</div>

Bu yerda $d$ — daryo kengligi, $\alpha$ — qayiq yönalişi bilan qirğoqqa perpendikulyar yönaliş orasidagi burçak (oqimga qarşi tomonga burilganda musbat).

Qayiqni qarşi qirğoqqa faqat tezlikning qirğoqqa perpendikulyar taşkil etuvçisi olib boradi, şuning uçun yönaliş burçagi özgarmasa, oqim kesib ötiş vaqtiga taʼsir qilmaydi. Qayiq oqimga perpendikulyar yönaltirilganda ($\alpha = 0$) daryo eng tez kesib ötiladi, lekin oqim qayiqni pastga surib ketadi. Aynan röparadagi nuqtaga yetiş uçun qayiqni oqimga qarşi buriş kerak. Bunda kesib ötiş uzoqroq davom etadi va bu faqat qayiqning suvga nisbatan tezligi oqim tezligidan katta bölgandagina mumkin.

“Suvga nisbatan kuzatiş” rejimini yoqing va pökak bilan birga suzing. Bu harakatlanuvçi sanoq sistemasida suv tinç turadi, qayiq özi yönaltirilgan tomonga töğri çiziq böylab harakatlanadi, qirğoqlar esa $-\vec u$ tezlik bilan siljiydi.

<div class="lesson-note">

Qayiqning tezligi, yönaliş burçagi va oqim tezligi <span class="param-tag live">darhol</span> belgili: qayiqni daryo örtasida ham boşqariş mumkin. Daryo kengligi özgartirilsa, harakat boşidan boşlanadi.

</div>

## Sinab köring

1. Qayiqni oqimga perpendikulyar yönaltiring ($\alpha = 0$), söng oqim tezligini oşiring. Kesib ötiş vaqti uzayadimi? “Daryo eniga” grafigini tekşiring.
2. Qayiq aynan start nuqtasining röparasiga yetib boradigan yönaliş burçagini toping. Uni $\sin\alpha = \dfrac{u}{\upsilon'}$ bilan soliştiring.
3. “Suvga nisbatan kuzatiş” rejimini yoqing. Endi qayiq qanday trayektoriya böylab harakatlanadi va nima uçun start nuqtasi siljib ketadi?
4. “Kuçli oqimga qarşi suziş” holatini tanlang. Qayiq oqimga qarşi yönaltirilgan bölsa ham, nima uçun oqim uni baribir pastga surib ketadi?

## Masalalar

### 1-masala. Oqimga perpendikulyar suziş

Eşkakçi qayiqni kengligi 60 m bölgan daryoda oqimga perpendikulyar yönaltiradi. Qayiqning suvga nisbatan tezligi $3{,}0\ \text{m/s}$, oqim tezligi $1{,}5\ \text{m/s}$. Qayiq daryoni qança vaqtda kesib ötadi, start nuqtasidan oqim böylab qança pastda qarşi qirğoqqa yetib boradi va uning qirğoqqa nisbatan tezligi qança?

<SimExample :values='{"w":60,"vb":3,"heading":0,"u":1.5}' check="Qayiq t = 20,00 s da qarşi qirğoqqa start nuqtasidan oqim böylab 30,0 m pastda yetib keladi; “Qirğoqqa nisbatan tezlik” körsatkiçida 3,35 m/s çiqadi.">

::: details Yeçimni körsatiş

1. Qayiqni qarşi qirğoqqa faqat tezlikning qirğoqqa perpendikulyar taşkil etuvçisi olib boradi: $t = \dfrac{d}{\upsilon'} = \dfrac{60}{3{,}0} = 20{,}0\ \text{s}$.
2. Şu vaqt içida suv qayiqni oqim böylab surib ketadi: $x = u\,t = (1{,}5)(20{,}0) = 30{,}0\ \text{m}$.
3. Qirğoqqa nisbatan tezlik: $\upsilon = \sqrt{3{,}0^2 + 1{,}5^2} = 3{,}35\ \text{m/s}$. U qirğoqqa perpendikulyar yönalişdan oqim böylab $\operatorname{arctg}\dfrac{1{,}5}{3{,}0} = 26{,}6^\circ$ ga oğgan.

**Javob.** Qayiq daryoni $20{,}0\ \text{s}$ da kesib ötadi va start nuqtasidan oqim böylab $30{,}0\ \text{m}$ pastda qirğoqqa yetib boradi; uning qirğoqqa nisbatan tezligi $3{,}35\ \text{m/s}$.

:::

</SimExample>

### 2-masala. Röparadagi nuqtaga yetib boriş

Suvga nisbatan $4{,}0\ \text{m/s}$ tezlik bilan suzadigan qayiq kengligi 80 m, oqim tezligi $2{,}0\ \text{m/s}$ bölgan daryoni kesib ötib, aynan start nuqtasining röparasiga yetib borişi kerak. Qayiqni qanday yönaltiriş kerak va u daryoni qança vaqtda kesib ötadi?

<SimExample :values='{"w":80,"vb":4,"heading":30,"u":2}' check="Qayiq t = 23,09 s da qarşi qirğoqqa aynan start nuqtasining röparasida yetib keladi. “Suvga nisbatan kuzatiş” rejimini yoqing: suvga nisbatan qayiq daryoni qiya çiziq böylab kesib ötadi.">

::: details Yeçimni körsatiş

1. Qayiq oqim böylab surilmasligi uçun uning tezligining oqimga qarşi taşkil etuvçisi oqim tezligiga teng bölişi kerak: $\upsilon'\sin\alpha = u$, demak $\sin\alpha = \dfrac{2{,}0}{4{,}0} = 0{,}5$, yaʼni $\alpha = 30^\circ$ (oqimga qarşi tomonga).
2. Qirğoqqa perpendikulyar taşkil etuvçi: $\upsilon'\cos\alpha = 4{,}0\cos 30^\circ = 3{,}46\ \text{m/s}$.
3. $t = \dfrac{80}{3{,}464} = 23{,}1\ \text{s}$. Qayiq oqimga perpendikulyar yönaltirilganda bu vaqt $20{,}0\ \text{s}$ bölardi, lekin oqim uni 40 m surib ketardi.

**Javob.** Qayiqni oqimga qarşi tomonga $\alpha = 30^\circ$ ga buriş kerak; u daryoni $23{,}1\ \text{s}$ da kesib ötadi.

:::

</SimExample>

### 3-masala. Oqim qayiqdan tezroq bölganda

Suvga nisbatan $2{,}0\ \text{m/s}$ tezlik bilan suzadigan qayiq kengligi 50 m, oqim tezligi $4{,}0\ \text{m/s}$ bölgan daryoni kesib ötadi. U röparadagi nuqtaga yeta olmaydi. Qayiq oqimga qarşi tomonga $\alpha = 30^\circ$ ga burilganda oqim uni eng kam surib ketadi. Bunda qayiq daryoni qança vaqtda kesib ötadi va start nuqtasidan oqim böylab qança pastda qirğoqqa yetib boradi? Natijani qayiq oqimga perpendikulyar yönaltirilgan hol bilan soliştiring.

<SimExample :values='{"w":50,"vb":2,"heading":30,"u":4}' check="Qayiq t = 28,87 s da qarşi qirğoqqa start nuqtasidan oqim böylab 86,6 m pastda yetib keladi. Soliştiriş uçun yönaliş burçagini 0° ga qöying.">

::: details Yeçimni körsatiş

1. Qirğoqqa perpendikulyar taşkil etuvçi: $\upsilon'\cos 30^\circ = 2{,}0\cos 30^\circ = 1{,}732\ \text{m/s}$, demak $t = \dfrac{50}{1{,}732} = 28{,}9\ \text{s}$.
2. Oqim böylab taşkil etuvçi: $u - \upsilon'\sin 30^\circ = 4{,}0 - 1{,}0 = 3{,}0\ \text{m/s}$, demak $x = (3{,}0)(28{,}87) = 86{,}6\ \text{m}$.
3. Oqimga perpendikulyar yönaltirilganda: $t = \dfrac{50}{2{,}0} = 25{,}0\ \text{s}$ va $x = (4{,}0)(25{,}0) = 100\ \text{m}$. Qayiqni $\sin\alpha = \dfrac{\upsilon'}{u}$ böladigan burçakka oqimga qarşi buriş surilişni taxminan 13 m ga kamaytiradi, lekin kesib ötiş vaqtini taxminan 4 s ga oşiradi.

**Javob.** $28{,}9\ \text{s}$ va oqim böylab $86{,}6\ \text{m}$; qayiq oqimga perpendikulyar yönaltirilganda esa $25{,}0\ \text{s}$ va $100\ \text{m}$.

:::

</SimExample>
